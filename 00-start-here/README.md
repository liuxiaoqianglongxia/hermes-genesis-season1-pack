# Hermes Genesis 第一季实战资料包

这份资料包是给读完《Hermes Genesis》第一季后，想把方法搬到自己项目里的读者准备的。

它不是完整 Hermes，也不是商业系统，更不是安装器。

它更像一份脱敏后的施工手册：把第一季里反复踩坑后沉淀出来的目录、事实源、团队协作、角色记忆、可观测系统和任务提示词，整理成可以照着改的模板。

建议使用方式：

1. 先读 `01-season-roadmap/three-replication-routes.md`，选择自己要走的路线。
2. 如果只是想让 AI 不乱放文件，从 `02-foundation-structure-facts/` 开始。
3. 如果想让一个 AI 管多个团队，再看 `03-team-workbench/`。
4. 如果想做团队角色和经验沉淀，再看 `05-roles-and-memory/`。
5. 如果想看系统运行状态，再看 `06-dashboard-observability/`。
6. 最后用 `08-pitfalls-and-checklists/safety-checklist.md` 做发布前检查。

推荐做法：不要一次抄完。先复制一个 demo 项目，跑通“目录清楚、事实源清楚、进度清楚”这三件事，再逐步增加团队和角色。
