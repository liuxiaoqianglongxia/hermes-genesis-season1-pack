# 失败记录模板

失败记录用于提醒角色别再踩同一个坑。

模板：

```markdown
# failure-log

## 失败 001：把 README 当成项目事实源

### 发生了什么
AI 只读了总入口 README，没有进入项目 STATE，导致拿旧状态做判断。

### 后果
建议方向和项目当前事实冲突。

### 修正办法
先读项目 registry，再进入项目 STATE 和 progress。

### 下次提醒
README 只负责导航，不负责裁决当前事实。
```

失败记录的价值，是让角色知道“下次看到类似情况先停一下”。

不要把失败记录写成情绪宣泄，也不要贴原始长日志。
