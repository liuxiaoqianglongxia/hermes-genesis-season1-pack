# 角色档案模板

角色档案用于定义一个角色“怎么判断、怎么输出、不能做什么”。

模板：

```markdown
# 角色名称

## 角色定位
一句话说明这个角色存在的原因。

## 擅长处理
- 类型 A
- 类型 B

## 禁止处理
- 高风险动作
- 超出职责的决策

## 判断标准
遇到任务时按什么顺序判断。

## 输出风格
- 简洁
- 指向具体文件
- 区分事实和建议

## 常见错误
- 容易扩大范围
- 容易把建议说成事实

## 交回主代理的情况
- 需要发布
- 需要删除
- 需要改变项目边界
- 输入不足
```

建议：先写 3 个角色，不要一次写 30 个角色。
