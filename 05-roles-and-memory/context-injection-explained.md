# 上下文注入说明

上下文注入的目的，是不要再赌 AI 会自觉读对文件。

朴素做法：在派单前，把任务相关的事实直接塞给子代理。

推荐注入内容：

- 任务目标
- 项目 STATE 摘要
- 最近 progress 摘要
- 相关角色档案
- 相关角色记忆
- 禁止事项
- 输出格式

伪代码：

```text
读取项目注册表
找到目标项目
读取项目 STATE
读取最近 progress
读取角色档案
读取角色记忆摘要
拼成派单上下文
交给子代理执行
```

不要注入：

- 无关团队的完整历史
- 大段原始聊天
- 敏感运行材料
- 已归档但未标注的旧事实

注入不是越多越好，而是要把“这次任务必需的事实”放到子代理眼前。
