# 角色记忆说明

角色记忆不是聊天记录仓库。

它只保存对未来仍然有用的经验，例如：

- 这个角色容易犯什么错
- 某类任务的固定检查顺序
- 某个项目的长期边界
- 用户反复强调的偏好

不应该保存：

- 一次性的任务进度
- 临时日志
- 大段原始对话
- 已经过期的中间结论
- 敏感运行材料

最小目录示例：

```text
roles/
└── product-manager.md

memories/
└── product-manager/
    ├── experience-log.md
    └── failure-log.md
```

写入原则：

1. 能让未来少犯错，才值得写。
2. 写成事实，不写成命令。
3. 不确定的内容不要写入长期记忆。
