# 子代理任务边界

子代理适合做“有明确边界的劳动”，不适合做最终决策。

适合交给子代理：

- 扫描文件是否缺章节
- 对照清单检查风险
- 阅读多个文件并汇总差异
- 生成候选方案
- 做一次独立审稿
- 跑只读验证

不适合直接交给子代理：

- 删除文件
- 发布内容
- 提交最终版本
- 修改全局规范
- 决定商业承诺
- 处理敏感凭据

派单模板：

```markdown
你是一个只读检查子代理。

目标：检查资料包是否存在过度承诺。
范围：只读 packages/example-pack/ 下的 Markdown 文件。
禁止：不要修改文件，不要调用外部接口，不要生成发布内容。
重点检查：完整产品、一键安装、保证跑通、一对一服务等表达。
输出：按 P0/P1/P2 分级列出风险句和建议改法。
```

验收原则：子代理说“没问题”不等于真的没问题。主代理仍要抽样回读。
