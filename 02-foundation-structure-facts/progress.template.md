# progress.md 模板

`progress.md` 负责记录项目推进过程。

建议模板：

```markdown
# 项目进度

## 2026-xx-xx

### 本轮目标
写清楚本轮要解决什么。

### 本轮动作
- 做了什么
- 改了哪些文件
- 验证了什么

### 结果
- 成功项
- 失败项
- 未完成项

### 下一步
只写下一轮最应该做的 1-3 件事。

### 风险
记录会影响后续判断的风险。
```

写法建议：

- 过程记录可以比 STATE 更细。
- 但不要贴大段运行日志。
- 如果某个决定已经稳定，应回写 STATE，而不是只留在 progress。
