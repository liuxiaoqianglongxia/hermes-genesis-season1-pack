# 术语表示例

术语表的目标不是显得专业，而是减少 AI 和人之间的误解。

建议先定义这些词：

| 术语 | 建议定义 | 反例 |
| --- | --- | --- |
| 事实源 | 当前最可信、最应该被引用的文件 | 历史聊天记录 |
| 导航层 | 告诉 AI 去哪里找事实的入口 | 大杂烩 README |
| 展示层 | 给人看的页面或文档 | 用来覆盖事实的页面 |
| 项目状态 | 项目当前真实状态 | 某次阶段总结 |
| 项目进度 | 按时间记录的过程 | 当前唯一事实 |
| 团队边界 | 哪个团队负责什么 | 角色名随便混用 |
| 子代理 | 被派去完成具体任务的执行者 | 另一个总控 |
| team-boss | 负责拆任务、定边界、验收的总控角色 | 万能执行工 |

写术语表时，尽量用一句话解释。

不要写成百科。百科越长，AI 越容易抓错重点。
