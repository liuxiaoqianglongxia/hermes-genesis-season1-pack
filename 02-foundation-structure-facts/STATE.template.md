# STATE.md 模板

`STATE.md` 只写项目当前状态。

建议模板：

```markdown
# 项目状态

## 1. 项目一句话
这个项目解决什么问题？给谁用？

## 2. 当前阶段
- planning / building / testing / stable / paused

## 3. 当前目标
本阶段最重要的 1-3 个目标。

## 4. 当前事实
- 已确定的架构
- 已确定的目录
- 已确定的边界

## 5. 明确不做
- 本阶段不做什么
- 哪些需求以后再说

## 6. 入口文件
- 进度：docs/progress.md
- 任务清单：docs/tasks.md（如有）
- 设计说明：docs/design.md（如有）

## 7. 最近人工决定
只记录仍然有效的决定，不写流水账。
```

使用提醒：

- 每次重大方向变化后更新。
- 不要把每天的执行日志塞进来。
- 不确定的内容标“待确认”，不要伪装成事实。
