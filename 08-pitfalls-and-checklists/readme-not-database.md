# README 不是数据库

常见翻车：README 一开始只是导航，后来被越写越长，最后变成所有事实的大杂烩。

症状：

- README 里开始记录每日进度。
- README 里有多个项目的当前状态。
- README 里同时写规范、历史、任务和结论。
- AI 每次只读 README，就以为已经掌握全部事实。

修正：

1. README 只保留入口和查找顺序。
2. 当前项目事实放 STATE。
3. 项目过程放 progress。
4. 历史材料标归档，不参与当前裁决。
5. 如果 README 和 STATE 冲突，以 STATE 为准，并修正 README 指路。

一句话：README 负责告诉 AI 去哪里，不负责替所有文件说话。
