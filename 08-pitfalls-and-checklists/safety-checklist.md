# 安全自查清单

交付任何资料包前，至少检查下面这些项。

内容边界：

- 是否把资料包说成完整系统？
- 是否承诺安装服务？
- 是否承诺保证跑通？
- 是否把 Dashboard 说成产品？
- 是否混入真实发布链路？

文件边界：

- 是否包含真实运行数据库？
- 是否包含真实会话材料？
- 是否包含备份目录？
- 是否包含草稿载荷？
- 是否包含本机绝对路径？
- 是否包含敏感凭据？

表达边界：

- GitHub 是公开基础版，不是完整内部源码。
- Dashboard 是参考项目，不是开箱即用产品。
- 资料包是脱敏实战材料，不是商业系统。
- 赞赏是支持系列，不是购买一对一服务。

如果任何一项不确定，先停下来人工复核。
