# dashboard-lite

这是一个静态仪表盘演示，用来展示 AI Agent 工作台可以如何呈现运行状态。

它不是完整 Dashboard 后端。

## 使用方式

直接用浏览器打开：

```text
index.html
```

不需要安装依赖，不需要启动服务，不连接真实系统。

所有数据来自：

```text
sample-data.js
```

## 展示区块

- 端口状态
- Agent / 角色
- 定时任务
- 技能
- 流水线
- 用量观察
- 轻量 memory status

## 注意

这里的所有数据都是虚构 demo。不要把真实端口、真实路径、真实密钥、真实日志放进公开仓库。
