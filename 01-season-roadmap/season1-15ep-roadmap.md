# 第一季 15 篇路线图

第一季可以按一条主线理解：从“AI 每次都乱猜”到“AI 有目录、有事实源、有团队边界、有可观测入口”。

阅读顺序建议：

1. 官宣篇：为什么要把这段历史写成一季。
2. EP-001：AI 不是靠聊熟变聪明，先要有目录规矩。
3. EP-002：规范多了以后，问题开始出现。
4. EP-003：README 只负责导航，不能当动态事实源。
5. Code Drop 01：基础规范和模板第一次放出。
6. EP-004：一个会话干不了所有事，子代理开始上场。
7. EP-005：team-boss 出现，但不能写成大杂烩。
8. EP-006：团队技能和角色档案要拆开。
9. EP-007：靠 AI 自觉读文件不可靠，要提前注入上下文。
10. EP-008：子代理必须防卡死，不能看起来很努力却原地打转。
11. EP-009：团队一多，最怕串线。
12. Code Drop 02：单实例总控多团队骨架放出。
13. EP-010：长期稳定靠固定动作，不靠临时例外。
14. EP-011：Dashboard 出来以后，系统运行状态开始可见。
15. EP-012：系统开始整理自己的历史，第一季可以收束。

如果时间有限，不必从第一篇开始。先按“三条复制路线”选一个入口即可。
