# 项目经理先行工作流

很多 AI 项目失败，是因为一开始就让工程角色动手。

推荐顺序：

1. PM 先写问题定义。
2. PM 写本期范围和不做范围。
3. PM 写验收标准。
4. 工程角色基于验收标准给实现方案。
5. 测试角色基于验收标准做检查。
6. 主代理汇总，决定是否进入下一轮。

PM 输出模板：

```markdown
## 本期目标
一句话说明要解决什么。

## 用户场景
谁在什么情况下使用。

## 本期包含
- 功能 A
- 功能 B

## 本期不包含
- 暂不做功能 C
- 暂不做自动化部署

## 验收标准
- 打开页面能看到列表
- 能按状态筛选
- 每条记录能看到负责人
- 无关页面不受影响
```

PM 的价值不是写得多，而是先把“别做什么”说清楚。
