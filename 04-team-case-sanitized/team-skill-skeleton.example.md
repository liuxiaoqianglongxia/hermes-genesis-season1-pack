# 团队技能骨架示例

团队技能不要写成百科。

建议只包含四类内容：

```markdown
# product-team skill

## 适用场景
当任务涉及需求、范围、验收、优先级时使用。

## 团队边界
本团队负责定义问题和验收标准，不负责直接实现。

## 标准流程
1. 读取项目 STATE。
2. 读取最近 progress。
3. 明确本期目标。
4. 写本期包含和不包含。
5. 输出验收清单。

## 输出格式
- 本期目标
- 本期范围
- 不做范围
- 验收标准
- 需要工程确认的问题
```

不要放进去的内容：

- 所有历史项目复盘
- 每个角色的完整人格设定
- 真实内部群规则
- 发布链路
- 敏感运行信息

技能是流程骨架，角色档案才放角色经验。
